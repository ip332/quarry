# Quarry Python Runtime

`quarry-runtime-python` is the pure-Python runtime used by code generated by
Quarry's Python backend. It is importable as `quarry.runtime.python` and has
no runtime dependencies outside the Python standard library.

The package supports Python 3.9 and newer. Build local wheel and source
distribution artifacts with:

```sh
python -m pip install -e '.[test]'
python -m build
```

Generated modules import the runtime and check
`QUARRY_GENERATED_CODE_API_VERSION_PYTHON` at import time. Use a compatible
compiler-generated package and runtime installation. The package is not yet
published to PyPI.
